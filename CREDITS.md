# Credits

Full Stack Founder runs these open-source projects. Thank you to every author.

**How they're included.** Most of the skills ship inside this plugin as pinned copies (`plugin/vendor/`), unchanged from the upstream release named below, each folder with the project's own licence file (and NOTICE, where there is one). They stay under their own licences: Full Stack Founder's MIT licence covers only its own code. Impeccable and Playwright are installed separately, from their own repositories. To use one of these skills outside Full Stack Founder, install the original from its author's repo.
