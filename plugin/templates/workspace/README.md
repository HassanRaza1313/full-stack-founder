# Your studio (Full Stack Founder workspace)

Your private studio workspace: your ideas, portfolio, lessons and settings. The Full Stack Founder plugin reads it through the `STUDIO_DIR` environment variable, which `/founder:setup` set.

| Path | What it is |
|---|---|
| `studio.config.json` | Shared settings: this repo, your GitHub account, your domain, the demo limit |
| `studio.config.local.json` | This machine's folders (gitignored) |
| `ideas/<slug>/` | Research for ideas that don't have a product repo yet |
| `playbooks/` | Your own playbooks for `/founder:run` (copy a built-in one to start) |
| `PORTFOLIO.md` | Generated by `/founder:portfolio`; don't edit |
| `LEARNINGS.md` | Lessons across every project |

Ideas themselves are this repo's GitHub issues. Start with `/founder:portfolio`.
