# 0001. Stack

Status: accepted (studio default)

- **Repo:** pnpm + Turborepo, with `apps/web`, `packages/shared`, and `apps/mobile` added once mobile is validated.
- **Web:** Next.js App Router + Tailwind + shadcn/ui.
- **Mobile:** Expo + NativeWind.
- **Backend:** Supabase (Postgres, Auth, Storage, Edge Functions).
- **Tests:** Vitest for units, Playwright end to end, Maestro on mobile.
- **Lint and format:** Biome.

**Why:** one TypeScript codebase that one person can run, which Claude writes well, and which is free until production.
